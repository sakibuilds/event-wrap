# Event Wrap

Post-event communication pack generator. Fill in one event brief — name, date,
format, speakers, partners, links, highlights — and get copy-ready blocks:
speaker thank-you emails, attendee recap emails, partner thank-you notes, an
internal team recap, and a social post. Each block has a subject line, one-click
copy, and the whole pack can be downloaded as a .txt.

Pure client-side (Next.js + Tailwind). Draft persists in localStorage. No
backend, no accounts, no data leaves the browser.
